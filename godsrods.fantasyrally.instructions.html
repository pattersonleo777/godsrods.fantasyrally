02

Local Asset Monitoring

You must place your 3D files in the local directory before pushing to the cloud.

  • Folder: universe/public/assets/models/
  • Format: Use .gltf or .glb for fastest web loading.
  • Sync: Run git add . && git commit -m "update assets"
03

Netlify Logs Access

To see why a server error occurs (like "TypeError: fetch failed"):

  1. Log in to Netlify.
  2. Go to Functions tab.
  3. Click on auth.js to see real-time console logs.
